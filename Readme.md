# 📊 SQL Portfolio — Northwind Database  

This project highlights my **SQL querying skills** using the classic **Northwind** sample database.  
It serves as a portfolio to demonstrate both technical proficiency and analytical thinking applied to relational data.  

---

## 📂 Project Structure  
- **queries/** – a collection of SQL queries grouped by topic  
- **README.md** – project overview and description  

---

## 🧩 Skills Demonstrated  
✔️ Data selection and filtering (SELECT, WHERE, ORDER BY)  
✔️ Joining multiple tables (INNER JOIN, LEFT JOIN, etc.)  
✔️ Aggregation and grouping (GROUP BY, HAVING)  
✔️ Subqueries for advanced filtering and analysis  
✔️ Window functions for ranking and analytics  

---

## 📈 Example Use Cases  
🔹 Identify top customers by sales volume  
🔹 Analyze product categories and regional performance  
🔹 Rank customers and products using window functions  
🔹 Explore order history and employee performance
